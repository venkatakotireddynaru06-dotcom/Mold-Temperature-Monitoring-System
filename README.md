# Mold Temperature Monitoring System

A Flask-based web application that simulates real-time mold temperature monitoring for manufacturing environments. This project demonstrates how process engineers can monitor mold temperatures, analyze trends, and receive recommendations to improve production quality.

## Features

- Real-time temperature simulation
- Live dashboard
- Temperature status (Low / Optimal / High)
- Production recommendations
- Temperature history (Last 10 readings)
- Temperature graph using Matplotlib
- Live clock
- Automatic dashboard refresh
- Production summary
- Responsive user interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Matplotlib

## Installation

1. Clone the repository

```bash
git clone https://github.com/venkatakotireddynaru06-dotcom/Mold-Temperature-Monitoring-System.git
```

2. Navigate to the project folder

```bash
cd Mold-Temperature-Monitoring-System
```

3. Install dependencies

```bash
pip install flask matplotlib
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit

```
http://127.0.0.1:5000
```
